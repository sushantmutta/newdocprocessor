------------------------------------

existing HITL behavior.

-------------------------------------
Added exact-match knowledge lookup between validation and final supervisor decision.

Changed files:
- config/settings.py
- src/core/state.py

- src/core/knowledge/__init__.py
- src/core/knowledge/knowledge_store.py

- data/knowledge/drug_aliases.csv

What changed:
- Added setting: ENABLE_KNOWLEDGE_LOOKUP (default false).
- Added setting: knowledge_dir (data/knowledge).
- Added state fields: knowledge_hits, knowledge_conflicts, knowledge_recommendations.
- Added curated exact-lookup store (JSON/CSV loading, normalization, aliases).
- Added knowledge agent node to compare extracted data to curated references.
- Added knowledge mismatch signal that can trigger human review via supervisor.
