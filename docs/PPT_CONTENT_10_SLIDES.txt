Slide 1: Project Title and Context
Agentic AI Document Processor for Medical Workflows

- Domain: Prescription and lab report processing in healthcare/insurance operations.
- Core challenge: Convert unstructured medical documents into safe, auditable, structured outputs.
- Constraints: Clinical risk, data quality variance, PHI/PII protection, and human oversight requirements.
- Tech direction: Multi-agent LangGraph pipeline with HITL, repair loops, knowledge checks, and traceability.


Slide 2: Problem Statement

- Manual review of medical documents is slow, expensive, and inconsistent.
- LLM-only extraction can miss schema constraints, clinical red flags, or unit mismatches.
- In-memory workflows lose pending review state on restart, making operations brittle.
- Teams need review queues, escalation, audit logs, and deterministic routing for production use.
- Regulatory and trust requirements demand explainable decisions and complete trace history.


Slide 3: Our Solution

- Built a multi-agent document intelligence pipeline using LangGraph.
- Introduced a deterministic supervisor for stage-wise routing and safety gating.
- Added Human-in-the-Loop interrupts with persistent SQLite checkpointing.
- Added feature-flagged knowledge-base lookup for curated medical consistency checks.
- Implemented a robust repair agent for structured correction with confidence-aware behavior.
- Added API-level trace and audit persistence for observability and compliance readiness.


Slide 4: High-Level Architecture

- Input layer: Upload APIs for PDF/TXT document ingestion.
- Orchestration layer: initialize -> supervisor gates -> extractor/validator/repair/redactor/reporter.
- Control layer: Supervisor routes to repair, human_review, redactor, or abort.
- HITL layer: human_review interrupt, decision APIs, timeout worker, escalation flow.
- Knowledge layer: Curated JSON/CSV exact-match lookup for drugs/lab tests.
- Persistence layer: SQLite for checkpoints, review queue, trace events, human audit decisions.
- Output layer: Validated structured data, redacted text, reports, trace records.
